# Assignment 6: Build and Evaluate Tree Models

## Overview

This repository contains the work completed for Assignment 6 using tree-based machine learning methods. The assignment includes a conceptual exercise on recursive binary partitioning, an applied comparison of ensemble tree methods, and participation in the Kaggle Multi-Class Prediction of Obesity Risk competition.

## Objectives

- Complete Conceptual Question #1 from ISLR Python.
- Complete Applied Question #12 from ISLR Python.
- Build and evaluate Decision Tree, Bagging, Random Forest, and Gradient Boosting models.
- Compare ensemble methods against logistic regression.
- Submit model predictions to Kaggle and evaluate performance.

## Files Included

- **Assignment6.ipynb** – Complete Jupyter notebook containing all code, analyses, figures, and interpretations.
- **Assignment6-JupyterLab.pdf** – PDF export of the completed notebook.
- **submission_tree.csv** – Decision Tree Kaggle submission.
- **submission_bagging.csv** – Bagging model Kaggle submission.
- **submission_rf_v2.csv** – Random Forest Kaggle submission.
- **submission_boost.csv** – Gradient Boosting Kaggle submission.
- **Kaggle Submission Screenshot.png** – Evidence of successful Kaggle submissions.

## Dataset

The models were developed using the Multi-Class Prediction of Obesity Risk dataset from Kaggle.

Competition:
[https://www.kaggle.com/competitions/playground-series-s4e2/submissions]

## Results

| Model | Kaggle Score |
|---------|---------|
| Decision Tree | 0.87554 |
| Bagging | 0.89116 |
| Random Forest | 0.89017 |
| Gradient Boosting | 0.90200 |

Gradient Boosting achieved the highest performance among the tree-based methods evaluated.
